# plug_figma

Плагин для Figma: вставляешь HTML — получаешь **редактируемые слои**: фреймы, тексты, картинки, иконки и Auto Layout. Без сервера, без подписки, всё работает локально внутри Figma.

## Установка

1. Скачай репозиторий (**Code → Download ZIP**) и распакуй, или `git clone https://github.com/delusional2/plug_figma.git`.
2. Открой **десктопное приложение Figma** (в браузерной версии плагины из файлов не ставятся).
3. В любом файле: **Plugins → Development → Import plugin from manifest…** и выбери `manifest.json` из этой папки.
4. Запуск: **Plugins → Development → HTML → Figma**.

## Как пользоваться

1. Вставь HTML в поле, или нажми «Открыть файл…», или просто перетащи `.html` в окно плагина.
2. Выбери ширину экрана: десктоп 1440, ноутбук 1280, планшет 768, телефон 390 или свою.
3. Нажми **Импортировать** (или ⌘/Ctrl + Enter).

Для проверки есть пример: [`examples/landing.html`](examples/landing.html).

## Как это работает

Плагин не пытается «понять» CSS сам. Он отрисовывает страницу в настоящем браузере внутри окна плагина, ждёт шрифты, картинки и скрипты, прокручивает её (чтобы сработали анимации «появления при скролле»), а потом измеряет каждый элемент и переносит то, что получилось на экране:

| В браузере | В Figma |
|---|---|
| блоки с фоном, рамкой, тенью | фреймы с заливкой, обводкой, эффектами |
| `linear-` / `radial-` / `conic-gradient` | градиентные заливки |
| `border-radius`, `overflow: hidden` | скругления, Clip content |
| `box-shadow`, `filter: blur`, `backdrop-filter` | Drop/Inner shadow, Layer/Background blur |
| абзацы с `<b>`, `<i>`, `<a>`, `<span>` | один текстовый слой со стилизованными кусками |
| градиентный текст (`background-clip: text`) | градиентная заливка текста |
| `<img>`, `background-image`, `<video poster>`, `<canvas>` | картинки |
| inline `<svg>` (в т.ч. `currentColor`) | векторы |
| `<input>`, `<textarea>`, `<select>`, чекбоксы | фреймы с текстом значения / плейсхолдера |
| `position: absolute / fixed` | Absolute position внутри Auto Layout |

**Auto Layout** включается только там, где элементы уже стоят ровной строкой или колонкой с одинаковыми отступами — тогда результат совпадает с браузером один в один. Колонки «обнимают» содержимое (Hug), так что если поправить текст, всё ниже аккуратно сдвинется. Где Auto Layout не подходит (сетки, неравные отступы), слои остаются на абсолютных координатах. Галочкой в окне его можно выключить совсем.

**Шрифты** берутся из установленных в Figma: сначала тот, что указан в CSS, потом похожий (`sans-serif` → Inter, `monospace` → JetBrains Mono / Roboto Mono и т.д.), начертание подбирается по жирности и курсиву.

**Tailwind**: если вставить голый кусок разметки с классами Tailwind и без стилей, плагин сам подключит Tailwind CDN.

## Ограничения

- `::before` / `::after` не переносятся (иконочные шрифты вроде Font Awesome тоже — лучше SVG-иконки).
- Маркеры списков (точки, цифры) не рисуются.
- `transform: rotate/scale` не переносится — берётся итоговый прямоугольник.
- Картинка не загрузится, если сайт запрещает загрузку с других доменов (CORS) — тогда будет серая заглушка. Относительные пути (`img/photo.png`) из файла тоже не найдутся — нужны полные ссылки `https://…` или `data:`.
- `z-index` не учитывается: слои идут в порядке HTML.

## Файлы

- `manifest.json` — описание плагина для Figma.
- `ui.html` — окно плагина; внутри же «агент», который запускается внутри отрисованной страницы и измеряет её.
- `code.js` — создаёт слои в документе Figma из присланного дерева.
