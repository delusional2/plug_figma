# plug_figma

Плагин для Figma, который превращает веб-страницу в **редактируемые слои**: фреймы, тексты, картинки, векторы и Auto Layout. Можно вставить HTML, дать ссылку (в том числе на `localhost`) или снять страницу прямо из браузера закладкой. Сервер и подписка не нужны, всё работает локально.

## Установка

1. Скачай репозиторий (**Code → Download ZIP**) и распакуй его. Или склонируй: `git clone https://github.com/delusional2/plug_figma.git`.
2. Открой **десктопное приложение Figma**. В браузерной версии плагины из файлов не ставятся.
3. В любом файле выбери **Plugins → Development → Import plugin from manifest…** и укажи `manifest.json` из этой папки.
4. Запуск: **Plugins → Development → HTML → Figma**.

## Три способа импорта

### 1. Вставить HTML или открыть файл

Вставь HTML в большое поле, нажми «Открыть файл…» или перетащи `.html` в окно плагина. Можно выбрать или перетащить сразу несколько файлов: они импортируются по очереди (в порядке имён) и встанут в ряд с отступом. Потом выбери ширину экрана (десктоп 1440, ноутбук 1280, планшет 768, телефон 390 или свою) и нажми **Импортировать** (или ⌘/Ctrl + Enter).

Подходят целые страницы, куски разметки с Tailwind-классами (плагин сам подключит Tailwind) и React-компоненты в JSX/TSX из v0, Claude или shadcn (их соберёт Babel прямо в плагине). Попробовать можно на [`examples/landing.html`](examples/landing.html).

### 2. По ссылке или с localhost

Впиши адрес в поле **«Ссылка или localhost»**: `https://example.com/page`, `localhost:5173` или просто номер порта `5173`, и нажми **Импортировать**. Плагин скачает страницу и отрисует её у себя. Относительные пути к стилям, картинкам и скриптам продолжат работать, потому что плагин добавляет в страницу `<base href>`.

- Порты локальных dev-серверов прописаны в `manifest.json` → `devAllowedDomains`: 3000, 3001, 4000, 4173, 4200, 4321, 5000, 5173, 5174, 5500, 8000, 8080, 8081, 8888. Если у тебя другой порт, допиши его туда (например, `"http://localhost:9000"`) и заново импортируй манифест. Figma не принимает адреса `127.0.0.1` в манифесте: плагин сам заменит такой адрес на `localhost`, а если сервер слушает только `127.0.0.1`, используй закладку (способ 3).
- Многие сайты не разрешают читать себя из чужого окна (CORS). Тогда плагин так и скажет и предложит закладку, см. способ 3.

### 3. Закладка «Скопировать для Figma»

Это лучший способ для живых сайтов, личных кабинетов за логином, SPA и всего, что не открывается по ссылке.

1. Открой `bookmarklet.html` из папки плагина в браузере и перетащи синюю кнопку на панель закладок.
2. Открой нужную страницу и нажми закладку. Через несколько секунд в углу появится окошко «Скопировано».
3. В плагине вставь скопированное (⌘/Ctrl + V) в большое поле и нажми **Импортировать**. Если браузер не дал скопировать, в окошке будут кнопка «Скопировать» и ссылка «Скачать .json»: этот файл можно перетащить в окно плагина или открыть через «Открыть файл…».

Закладка запускает **тот же самый код**, что и плагин, но на настоящей странице и с шириной твоего окна. Для мобильной версии сузь окно или включи режим устройства в DevTools. Если закладка не срабатывает (например, браузер ограничивает её длину), в `bookmarklet.html` есть код, который можно вставить в консоль (F12).

## Что переносится

Плагин не пытается «понять» CSS сам. Он отрисовывает страницу в настоящем браузере, ждёт шрифты, картинки и скрипты, прокручивает её до конца (чтобы сработали ленивые картинки и анимации «появления при скролле»), а потом измеряет каждый элемент и переносит в Figma то, что получилось на экране.

| В браузере | В Figma |
|---|---|
| блоки с фоном, рамкой, тенью | фреймы с заливкой, обводкой и эффектами |
| `linear-` / `radial-` / `conic-gradient`, в том числе повторяющиеся, `oklch`/`oklab` и `background-size/position/repeat` | градиентные заливки, а узоры вроде сетки из точек становятся плиткой-картинкой |
| рамки с разными сторонами, `double`, `outline`, `border-radius` (в том числе эллиптические и в процентах) | обводки по сторонам, скругления, отдельные слои для контура |
| `box-shadow` (с `spread` и `inset`), `filter` (`blur`, `drop-shadow`, `grayscale` и другие), `backdrop-filter` | тени, Layer/Background blur, цветовые фильтры, «запечённые» в цвета и пиксели |
| `clip-path`, `mask-image` | маски Figma |
| `transform` (поворот, отражение, наклон, масштаб) | поворот и трансформация слоя, а масштаб применяется к размерам |
| `z-index`, `position: absolute / fixed` | порядок слоёв как в браузере, Absolute position и Constraints. Шапки и нижние панели с `position: fixed` закрепляются при прокрутке (Fixed) |
| абзацы с `<b>`, `<i>`, `<a>`, `<span>`, `text-overflow`, `line-clamp` | один текстовый слой со стилизованными кусками и обрезкой строк |
| градиентный текст (`background-clip: text`) | градиентная заливка текста |
| `::before` / `::after`, счётчики, кавычки, иконочные шрифты (Font Awesome, Material) | настоящие слои; иконки рисуются картинкой из шрифта страницы |
| маркеры списков (точки, цифры, `list-style-image`, `::marker`) | текстовые или картиночные слои рядом с пунктом |
| `<img>`, `srcset`, `<picture>`, WebP/AVIF, `object-fit` / `object-position`, `background-image`, `<video poster>`, `<canvas>` | картинки с правильной обрезкой и масштабом |
| inline `<svg>`, `<use>` и спрайты, SVG в `data:` | векторы |
| `<input>`, `<textarea>`, `<select>`, чекбоксы, радио, слайдеры, `progress` / `meter`, выбор цвета и файла | фреймы, которые выглядят как контролы, с текстом значения или плейсхолдера |

**Auto Layout** включается только там, где элементы уже стоят ровной строкой или колонкой (flex, grid с равными колонками, обычный поток блоков), поэтому результат совпадает с браузером. Колонки «обнимают» содержимое (Hug), `flex-grow` растягивает слой (Fill), отрицательные отступы, выравнивание по базовой линии и `row-reverse` тоже учитываются. Если поправить текст, всё ниже аккуратно сдвинется. Где Auto Layout не подходит (сложные сетки, неравные отступы), слои остаются на абсолютных координатах. Галочкой в окне его можно выключить совсем.

**Шрифты** берутся из установленных в Figma. Сначала ищется шрифт из CSS, потом похожий (`sans-serif` → Inter, `monospace` → JetBrains Mono / Roboto Mono и т.д.), начертание подбирается по жирности и курсиву.

**Названия слоёв** осмысленные: сначала `aria-label` и `alt`, потом первые слова текста внутри, потом понятный класс (утилитарные вроде `flex`, `p-4` и сгенерированные вроде `sc0`, `css-1x2y` пропускаются) и только потом тег. Фрейм страницы называется по имени файла, а если файла нет, по `<title>` или заголовку `h1`: например, «01-pult · 1440».

**Прокручиваемые блоки.** Если страница прокручивается внутри своего блока (как в админках), галочка «Разворачивать прокручиваемые блоки на всю высоту» вытянет такие блоки, чтобы в макет попало всё. Закладка делает это всегда, а страницу возвращает в исходный вид.

**Большие страницы** не подвешивают Figma. Слои создаются порциями, в окне видно «Создаю слои 450 / 1200». Картинки уменьшаются до двойного размера, в котором они показаны на странице (не больше 4096 px). Фотографии сохраняются в JPEG, а картинки с прозрачностью в PNG. Одинаковые файлы передаются один раз.

## Ограничения

- **Это снимок.** Hover, фокус, анимации, видео и состояние «после клика» не переносятся, переносится то, что видно на экране в момент импорта.
- **Шрифты**, которых нет в Figma, заменяются похожими. Чтобы совпало точно, установи нужный шрифт на компьютер.
- **Картинки**, которые сайт запрещает загружать с других доменов, Figma пробует скачать сама. Если и это не удалось, на их месте будет серая заглушка.
- **Импорт по ссылке** не сработает для сайтов без CORS. SPA с dev-сервера (Vite и т.п.) может не запуститься в изолированном окне плагина. В обоих случаях используй закладку.
- **Закладка**: строгая политика безопасности (CSP) некоторых сайтов может не дать ей загрузить картинки; тогда их докачает плагин по ссылке. Во время снимка на странице отключаются анимации, после снимка её можно просто обновить. Очень длинные закладки поддерживают не все браузеры: в Chrome, Edge, Arc и Яндекс Браузере закладка работает, в остальных браузерах есть вариант через консоль.
- **`<iframe>`** (YouTube, карты, виджеты) и `<audio>` становятся серыми прямоугольниками нужного размера.
- Списки с выбором нескольких пунктов (`<select multiple>`) показываются без строк-вариантов.
- Внешние `.svg` по ссылке приходят картинкой (в 2× размере), а не векторами. Векторами становятся inline `<svg>` и SVG в `data:`.
- Списки в Figma не становятся «нативными» (маркеры — отдельные слои рядом с текстом).
- У иконок Material Symbols не учитываются `FILL` / `wght` из `font-variation-settings`.
- Сетки с неравными отступами между колонками остаются на абсолютных координатах, без Auto Layout.

## Файлы

- `manifest.json` — описание плагина для Figma (сеть: все сайты и порты localhost для разработки).
- `ui.html` — окно плагина. Внутри «агент» (`pageAgent`), который запускается внутри отрисованной страницы и измеряет её, и подготовка страницы (Tailwind, JSX, `<base href>`).
- `code.js` — создаёт слои в документе Figma из присланного дерева.
- `bookmarklet.html` — закладка «Скопировать для Figma». Собирается из `ui.html` командой `node dev/build-bookmarklet.mjs`; после изменений в агенте её нужно пересобрать.

## Для разработки

Нужен установленный Google Chrome, npm-зависимостей нет.

- `node dev/fidelity.mjs [фильтр…] [-w 390]` — прогоняет страницы из `dev/cases`: снимает оригинал, запускает агента как в плагине, проверяет `code.js` на строгом макете Figma API (`dev/mock-figma.js`), перерисовывает результат (`dev/render.html`) и сравнивает попиксельно. Картинки и JSON лежат в `dev/out/`, последние цифры по каждой странице — в `dev/baseline.json`.
- `node dev/test-import.mjs [страница…] [-w 390]` — проверяет закладку на страницах из `dev/cases`, импорт по ссылке (`dev/fixtures/url-page` с относительными путями) и окно плагина с payload и ссылкой.
- `node dev/build-bookmarklet.mjs` — пересобирает `bookmarklet.html`.
