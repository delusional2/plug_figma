Закладка «Скопировать для Figma»

Снимает страницу прямо в браузере — такой, какой ты её видишь: с твоей шириной окна, после входа в аккаунт, со всеми скриптами. Подходит для сайтов, которые плагин не может загрузить по ссылке (CORS), и для приложений на localhost.

Скопировать для Figma

  1. Перетащи синюю кнопку на панель закладок (показать панель: ⌘/Ctrl + Shift + B).
  2. Открой нужную страницу и нажми закладку. Подожди несколько секунд — в углу появится окошко «Скопировано».
  3. В Figma открой плагин HTML → Figma, вставь (⌘/Ctrl + V) в большое поле и нажми Импортировать.

Если браузер не дал скопировать, в окошке будет кнопка «Скопировать» и ссылка «Скачать .json» — файл можно просто перетащить в окно плагина.

Ширина в Figma = ширина окна браузера: для мобильной версии сузь окно или включи режим устройства в DevTools. Картинки с чужих сайтов, которые не отдаются странице, плагин докачает сам по ссылке. После снимка страница может чуть измениться (отключаются анимации) — просто обнови её.

Закладка не работает? Запусти код в консоли

Некоторые браузеры ограничивают длину закладок. Тогда открой страницу, нажми F12 → Console, вставь этот код и нажми Enter.

Собрано из ui.html командой node dev/build-bookmarklet.mjs — код закладки совпадает с тем, что плагин запускает у себя.
